## Project Overview

This is an **AI Product Description Generator** — a Laravel + Inertia + Vue 3 application that leverages AI to generate compelling product descriptions. The system uses caching for performance, database-backed queues for async processing, and structured logging via channels.

## Architecture

### Backend (Laravel 13)
- **Controllers**: `app/Http/Controllers` — handle HTTP requests
- **Models**: `app/Models` — Eloquent models with factories in `database/factories/`
- **Routes**: `routes/web.php` — web routes; `routes/console.php` — console commands
- **Configuration**: `config/` — cache, logging, queue, database settings

### Frontend (Inertia v3 + Vue 3)
- **Pages**: `resources/js/pages/*.vue` — server-rendered page components
- **Types**: `resources/js/types/` — TypeScript type definitions
- **Routes**: `resources/js/routes/` — generated by Wayfinder from Laravel routes
- **Actions**: `resources/js/actions/` — controller-generated TypeScript functions
- **Styling**: `resources/css/app.css` — Tailwind CSS v4 setup

### Infrastructure
- **Database**: SQLite (dev), migrations in `database/migrations/`
- **Cache**: Database-backed cache (configurable via `CACHE_STORE`)
- **Queues**: Database-backed async jobs (configurable via `QUEUE_CONNECTION`)
- **Logging**: Channel-based logging via `LOG_CHANNEL` and `LOG_STACK`

## Key Patterns

### Creating Models and Features
- Use `php artisan make:model ModelName --migration` to create models with migrations
- Always create factories: `php artisan make:factory ModelNameFactory`
- Create tests with Pest: `php artisan make:test FeatureName --pest`
- Use `Inertia::render('PageName', ['data' => $data])` instead of Blade views

### API & Type Safety
- Use **Wayfinder** to generate TypeScript functions from routes — import from `@/actions/` or `@/routes/`
- Define Laravel route names for Wayfinder: `Route::get('/...')->name('routeName')`
- Inertia automatically generates TypeScript definitions for passed props

### Caching & Performance
- Database cache store configured by default; switch via `CACHE_STORE` env var
- Cache expiration times in code, not config — use `Cache::put($key, $value, now()->addHours(24))`

### Async Processing
- Database queue configured by default; process with `php artisan queue:work`
- For one-off background jobs, dispatch from controllers: `DescriptionJob::dispatch($product)`

### Logging
- Use structured channels: `Log::channel('products')->info('Description generated', ['product_id' => $id])`
- Configure channels in `config/logging.php`

## Frontend Implementation Notes

- **Deferred Props**: When using `Inertia::defer()`, add a skeleton/placeholder loading state
- **Form Handling**: Use `useForm()` hook from `@inertiajs/vue3` for reactive forms
- **HTTP Requests**: Use `useHttp()` hook (Inertia v3) instead of Axios
- **Routing**: Call Wayfinder-generated functions to navigate: `route('home')` or use router

## Testing

- Feature tests go in `tests/Feature/` — test the full request/response cycle
- Unit tests go in `tests/Unit/` — test isolated logic
- Use factories for models: `User::factory()->create()`
- All tests run via: `php artisan test --compact`

## Common Issues

**Frontend changes not showing?**
- Run `npm run build` or `npm run dev` (dev server handles HMR)
- Restart `composer run dev` if Vite gets stuck

**Database migration error?**
- Check `database/migrations/` for syntax errors
- Run `php artisan migrate --refresh` to reset (dev only)

**Type errors in Vue files?**
- Run `npm run types:check` to see the full list
- Wayfinder types auto-generate; restart Vite if not picking up new routes

**Queue jobs not running?**
- Run `php artisan queue:work` to start the worker
- Check `config/queue.php` for connection settings

## File Naming Conventions

- **Models**: `PascalCase.php` (e.g., `Product.php`, `DescriptionGenerator.php`)
- **Controllers**: `PascalCaseController.php` (e.g., `ProductController.php`)
- **Vue Pages**: `PascalCase.vue` (e.g., `ProductDetails.vue`)
- **Vue Components**: `PascalCase.vue` (e.g., `ProductCard.vue`)
- **TypeScript Files**: `camelCase.ts` or `index.ts` for exports
- **Routes**: Named routes with `kebab-case` (e.g., `product.show`, `api.product.generate`)
